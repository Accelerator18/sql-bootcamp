# SQL Bootcamp

Учебные проекты по PostgreSQL и SQL, выполненные в рамках SQL Bootcamp в School 21.

В ходе проектов я прошёл путь от базовых SELECT-запросов до рекурсивных запросов, представлений, индексов и анализа производительности.

## Projects

### SQLB1 — Basics
Базовые SELECT-запросы, фильтрация, сортировка, условия и подзапросы.

### SQLB2 — Retrieving data
JOIN, UNION, INTERSECT, EXCEPT, подзапросы и операции над множествами.

### SQLB3 — Retrieving data deep dive
Различные виды JOIN, CTE, работа с NULL и более сложные запросы к нескольким таблицам.

### SQLB4 — DML
Работа с INSERT, UPDATE и DELETE.

### SQLB5 — Snapshots
Создание и использование Views и Materialized Views.

### SQLB6 — Salesman problem
Решение задачи коммивояжёра с помощью рекурсивного SQL-запроса.

### SQLB7 — Database index
Работа с B-Tree индексами и оптимизацией запросов.

Использовал EXPLAIN ANALYZE для просмотра планов выполнения и сравнения запросов до и после добавления индексов.

## Technologies

PostgreSQL, SQL, JOIN, CTE, Subqueries, UNION, INTERSECT, EXCEPT, DML, Views, Materialized Views, Recursive Queries, B-Tree Indexes, EXPLAIN ANALYZE
